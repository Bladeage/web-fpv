Steuerung

Belegung wie bei einer Funke im Mode 2.

W / SGas mehr / weniger. Der Wert bleibt stehen. A / DGieren links / rechts ↑ / ↓Nicken: Nase runter / Nase hoch ← / →Rollen links / rechts RNeustart VKamera: Drohne / Verfolger MFlugmodus wechseln P / EscEinstellungen öffnen und schließen

Touch: Linker Daumen hoch und runter ist Gas, seitlich ist Gieren. Rechter Daumen steuert Nicken und Rollen. Beim Loslassen bleibt das Gas stehen. Alles andere geht auf Mitte.

Ziel: Hängt vom Modus ab. Das nächste Ziel leuchtet grün, der grüne Marker zeigt die Richtung.

Tipp: Schweben braucht beim 5-Zoll etwa ein Viertel Gas. R setzt Drohne und Akku zurück.
